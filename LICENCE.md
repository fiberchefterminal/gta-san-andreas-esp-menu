## 🧩 About

**GTA San Andreas overlay Menu** is a curated list of GTA San Andreas open-source tools:

- **Overlays** — on-screen helpers, layout notes, entity markers, distance readouts
- **Quality-of-Life Helpers** — vehicle catalog, weapon notes, map markers, hud tweaks
- **Research Notes** — route layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 World Helpers
- Entity Markers — outline nearby vehicles and pickups for study
- Distance Readouts — show ranges to points of interest
- overlay Notes — expanded minimap overview
- Speed Readout — track player velocity in single-player

### 🎨 Catalog & Cosmetics
- Vehicle Catalog — browse cars, bikes, planes, boats
- Weapon Notes — organize loadout references
- Skin Notes — track player model variants
- Hud Tweaks — adjust on-screen info layout

### 🏋️ Route Layout
- Waypoint Notes — plan single-player routes
- Checkpoint Study — review mission segments
- Marker Colors — customize marker visibility
